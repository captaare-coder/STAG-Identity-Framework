# STAG Identity Framework

Created by: Hans Waldron

## About

STAG (Secure Trust Agent Gateway) is an experimental digital identity and trust framework created for learning and exploring public key infrastructure (PKI), certificates, digital signatures, and secure verification.

## Purpose

The goal of STAG is to create an evolving framework for understanding digital trust, identity verification, and secure software distribution.

## Components

* STAG Root Certificate (Public Trust Certificate)
* Hans Agent Certificate (Project Identity)
* Version Information
* Documentation
* Future Verification Tools

## Security Notice

Public certificates may be shared for verification purposes.

Never share private keys, passwords, or certificate files containing private keys.
